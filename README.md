# A — Portfolio for Abdul Aziz Chowdhury

This repository contains a lightweight, responsive portfolio site ready for GitHub Pages.

## Deploy
1. Create repo named `A` under `github.com/aaziz98`.
2. Add files `index.html`, `styles.css`, `script.js`, `README.md` and optionally `CV.pdf`.
3. Commit and push to `main`.
4. In GitHub → Settings → Pages, set Source to `main` branch and root `/`.
5. Visit `https://aaziz98.github.io/A/`.

## Customize
- Edit `index.html` to update text, project links, and publication links.
- Replace `CV.pdf` with your CV file to enable the download button.
- Add project images by inserting `<img>` tags inside project cards and adjust CSS.

## Notes
- Dark and light themes are stored in `localStorage`.
- No external frameworks required.
